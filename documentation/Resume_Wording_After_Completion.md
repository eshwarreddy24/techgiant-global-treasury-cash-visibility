# Resume wording — use only after you have completed the corresponding local steps

## If Excel model only is completed

**Global Treasury Cash Visibility & Reconciliation | Excel | Independent Simulated Case Study**
- Built a multi-currency cash position model using synthetic bank transaction data across five accounts in USD, GBP, EUR and INR, translating balances into USD using documented illustrative FX assumptions.
- Developed bank-to-GL reconciliation checks to identify missing postings, amount mismatches, duplicate references and GL-only entries; added a four-week scenario-based liquidity forecast.

## If Alteryx workflow is built and successfully run

Add:
- Built and ran an Alteryx workflow to aggregate GL postings, join bank and GL datasets on transaction reference/account/currency, and generate matched, missing, duplicate and amount-mismatch exception outputs.

## If Tableau dashboard is built

Add:
- Developed a Tableau dashboard to visualise consolidated cash by account, liquidity headroom, daily bank movements, four-week projected cash and reconciliation exceptions.

## Kyriba wording

Safe wording:
- “Kyriba Treasury Management training; reviewed Developer Portal API documentation for cash visibility and integration concepts.”

Do not write:
- “Implemented Kyriba”
- “Configured Kyriba in production”
- “Integrated Kyriba with SAP”
- “Executed live bank connectivity”
unless those activities were genuinely carried out in an authorised Kyriba environment.
