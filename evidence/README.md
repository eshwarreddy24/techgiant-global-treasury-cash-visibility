# Evidence guide

This folder is reserved for sanitised evidence from the Excel, Alteryx and Tableau work. Raw reference PDFs are intentionally not published because their full-page screenshots can expose local machine paths.

The project distinguishes three kinds of evidence:

1. **Reproducible outputs** — source CSVs, the Excel workbook, Python validation and automated tests.
2. **Historical tool evidence** — described in [`docs/tool-evidence/`](../docs/tool-evidence/) without publishing the raw PDFs.
3. **Design guidance** — rebuild instructions for a native Alteryx workflow and a current Tableau workbook.

The supplied preview PNGs at the project root are Excel reference images. They are not presented as current Tableau execution evidence.

Do not add credentials, tokens, private connection strings, personal data, client data, or screenshots from an unauthorized environment.
